# 🎬 MovieVerse

MovieVerse é uma aplicação web moderna desenvolvida com React, Vite e TMDB API, inspirada em plataformas de streaming como Netflix, Disney+ e Prime Video.

## 🚀 Funcionalidades

- Buscar filmes e séries
- Listar filmes populares
- Listar séries populares
- Exibir detalhes completos
- Trailer oficial
- Elenco
- Conteúdos semelhantes
- Sistema de favoritos
- Dashboard do usuário
- Tema Dark/Light
- Layout responsivo
- Animações com Framer Motion

## 🛠️ Tecnologias

- React
- Vite
- React Router DOM
- Context API
- Framer Motion
- React Icons
- TMDB API
- CSS3
